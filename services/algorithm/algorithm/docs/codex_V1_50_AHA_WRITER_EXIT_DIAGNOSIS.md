## 4. 为什么现有回退救不了这轮

对当时实际可用事实调用未改动的 `_grounded_fallback_clause`，全部不符合 20 字整条复制条件：

- 旧版 M09：50 字；M13：27 字；M17：172/166/165 可见字符。
- 新版 M03：94 字；M09：35/28 字；M13：27 字。

这些不是缺乏事实，而是事实记录天然比最终文案长。V1.49 保留更多长事实也不会自动让此回退具备摘要能力。

审计的 `DETERMINISTIC_FALLBACK_NOT_PROVABLY_SAFE` 在本次实际表示“没有可以完整复制且满足格式的事实”，不能读成“图像有安全问题”或“模型事实已被证明不真实”。随后再记录的 `WRITER_ITEM_MISSING` 是同一次本地回退未生成文本的后果，不是又发生一次模型调用失败。审计 `attempt=3` 是程序步骤编号，不代表第三次 API 请求。

不建议为救这轮而添加动物/场景模板、截取前 20 字，或把内部标题直接当作展示正文。这些都会改变表达或产品契约，而非解决 Writer 本身的交付能力。
