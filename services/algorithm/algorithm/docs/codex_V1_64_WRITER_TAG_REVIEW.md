这次有实际画面与调用记录支持的共性问题是：

1. **主事实可用不代表辅助代码可用**，错误可能成为最终 canonical 标签，也可能不入选；必须分别统计。
2. **不清楚的上游细节会被继承，分别真实的物件又可能被 Writer 合成未支持的关系**；两者责任位置不同，不能统称视觉模型识别失败。
3. **内部事实和用户记忆句子不是同一种产物**；单字段格式失败或一次连接失败，都可能触发过宽的文案回退并损失主题、可读性。
4. **卡片数、模型调用完成、可交付状态和用户价值不是同一个指标**；标题变短、标签偶尔正确、框架正常返回均不等于质量已验收。

## 后续横向复核方式

仅记录四类观察，不成为新增算法规则：

1. **画面 → 事实**：主体、动作和关键关系是否可支持；不足时注明图像不清楚或未查看其余帧。
