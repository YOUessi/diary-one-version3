# R5_27：全日视觉记忆驱动 Chapter 生成，LLM-as-a-Judge 留在外部评测

日期：2026-11-04。仓库 YOUessi/diary-one-version3，特性分支 feature/2026-10-30-chapter-v2-boundary。原始视频和JPEG仍放在用户Mac，后续模型只读获批真实来源帧。

## 核心角色纠正

用户要的是 ChatGPT 作为外部 LLM-as-a-Judge，逐张检查云端真正发布的Chapter。不要在云端再额外部署独立Judge。

所以此版特意不包含此前试写的 chapter_editorial_judge.py 或 visual_editorial_judge.py，也不调用 S07P、S07Q、S09D 等额外“评分选优”阶段。原有 S07V/W分组合同修复、S09A图片事实核验、S12独立真实性核验属于生成流程必要的验证门禁，不是额外部署的ChatGPT外部Judge。

现有外部58个Chapter、12组质量报告仍在 docs/benchmarks/SYDNEY_R526_LLM_AS_JUDGE_ALL12_20261104.md。新算法以后生成什么、图片好不好，仍由ChatGPT读取最终真实结果后进行外部评价。

## 云端实际修改

### 1. 来源内容过滤 source_content_gate.py

只对明确的视频片尾推广卡、含至少两类CTA（例如 Subscribe 和 Keep Watching）且处于真实素材序列末尾的情况作自动排除；真实拍摄的街头广告或只出现一个品牌的照片不自动删除。原始观察、视频和图片不删；最终publication ledger将其标记为NON_LIVED_SOURCE_CONTENT而非生活记忆。

### 2. 全日记忆 global_visual_memory.py

保留所有经过验证的fact ID、source ID、frame ID；按全天分散性和视觉事实具体程度提取最多48个高价值证据锚点。真实专有名称或连续文字的跨时间相似性仅作为未确认的身份候选，不能当作已经证明“这是同一地点”。导入顺序不等于设备采集时钟，禁止据此推断路线。

### 3. 跨时间主题融合 chapter_theme_hierarchy.py

S07T Episode发现和S07U Chapter规划读取全日视觉记忆，而非仅看少量按时间分布的观察文本。同一地点多次出现可以融合进同一个Chapter，不因“又看到同一建筑”而独立分章；不同活动也不因同一天或相邻而硬拼一起。依旧按真实源图事实归属编译，局部错误引用可有限修复。

### 4. 全章叙事证据 chapter_story_outline.py

以最终选中的图片为事实来源，建立每章所有Episode的具体视觉证据提纲，传给原有S11文案写作。避免整个CBD漫步只剩一句纪念品或花园只剩仙人掌。没有实际选入照片的Episode明确标注未展示，不得填充不存在的经历、时间关系或人物行为。S12原有独立图像与事实验证保持不变。

### 5. 原有视觉筛选保持不变

R5_26 的重要图片事实候选保护、S09A真实图片观察、S09B封面/组图选择继续生效；不额外增加云端LLM-as-a-Judge调用。封面表现仍由ChatGPT在最终结果上评测。

## 实际验收与限制

- 新增来源片尾门禁、跨时间视觉记忆、Episode级写作证据的单元与合同测试。
