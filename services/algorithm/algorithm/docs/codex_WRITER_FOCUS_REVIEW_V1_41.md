## C1：先保留骆驼的活动，再保留环境

记录：`95eacf32-9b6e-5b27-a4de-8679de21e258`。

- 核心：草坡上骆驼吃草、卧着或站着。来源为 13、12、10.jpg，见证据索引 F13、F12、F10。
- 补充：远山、开阔草地构成的环境。来源为 11.jpg 等，见 F11。
- 不展开：电线、面朝哪个方向、逐只数量、鞍具。这里是本次主题下的取舍，不是判定这些物体普遍没有价值；也不是逐项确认原始识别无误。
- 为什么到这里就够：主体及活动已经明确，环境又提供了不同于动物近照的画面感。再增加设施和装备容易回到识别清单。
- 氛围：可以讨论“闲适”这类画面概括，但它不是一个必须排进前三名的物体或事实，也不要求最终一定写出该词。

## C2：鹿与街道的组合，比街道里有哪些设施更值得讲

记录：`112e151b-cf25-5237-82b1-331140b6feb6`。

- 核心：鹿走在有建筑、路面的环境中。来源为 09、06.jpg，见 F09、F06。
- 补充：鹿在路边低头吃灌木或草。来源为 08、07.jpg，见 F08、F07。
- 不展开：白色汽车、黄色工程车、路障、垃圾桶、鹿身体颜色和精确形态清单。这些可以留在事实或索引里，文案不必承担全部信息。
- 为什么保留两个内容：前者体现这组画面的特点，后者补充不同动作；不用每张照片各分配一句描述。
- 本轮不做：将照片顺序写成“先穿街、后来觅食、最后离开”。这批输入没有可靠拍摄时间，不因事实文本或组织说明里有顺序词，就认定顺序已证实。
- 与 A1 的关系：A1 聚焦的过街动作本来就是这章的一部分。换词或增添氛围不自动产生独立故事；这里仅记录重叠疑点，不更改两条的入选状态。

## A2：食物是主角，街景提供具体处境

记录：`d43ab62f-4aac-5916-87e4-ae15ce6e24fb`。

## A3：保留人与窗口的关系，不把氛围词当主体

记录：`b316441b-1ddf-512c-a28d-aac89bd88c23`。

- 核心：餐车窗内有人操作，窗前站着人。来源为 19.jpg，见 F19。重点是这个共同构成的售卖场景，不是分开给人、车、窗口打三个分。
- 可选识别细节：招牌名称可让场所更具体，但本次没有个人兴趣或店铺重要性的反馈，因此先让人物活动居前，名称作为可选补充，不定为必写或必删。
- 不展开：哪人戴什么帽子、车身各块颜色的逐项描述。
- 氛围：画面允许讨论生活气息，但先前人工句子“小小餐车，透着街边的烟火气”只保留了餐车与抽象氛围，弱化了具体活动。本轮取舍进一步明确：不能仅以“烟火气”代替这张图片实际有意思的关系。该词没有被设为禁用或必用。
- 不补入：交付哪份食物、顾客说了什么、用户点了什么等不存在的具体行为。本轮也不要求重新查验所有可能错误。
- 与 C3 的独立性仍为待讨论，不在 Writer 阶段增加淘汰规则。

## 这轮能得出的共性结论

1. 应比较有意义的“主体与动作、人与环境”等内容关系，而不是机械取最高分的几个名词。
2. 先有核心，只有能补充区别、行为或环境的信息才继续加入。A1 一个内容单元足够，其他条目可以有必要补充；本轮不冻结统一数量。
3. 氛围来自已经选中的具体内容，是表达方式，不是看到场景标签就自动领取的一个词。
4. 文案精简不等于抹掉不方便解释的材料，也不负责制造 Aha 的独立价值。
5. 人工取舍尚不证明模型能自动做到；六条来自一个人的一个素材包，不能称为跨用户验证或个人兴趣模型。

后续若进入模型验证，建议仍用这六条，在一次 Writer 请求中返回少量“描述重点、对应事实、简短理由、正文”。这是待实施的方案，不是这轮已经新增的流程。本人工表用于比较取舍，不应直接变成给模型抄的场景答案，也不以逐词匹配作为通过条件。
