## 关键修复与根因

- 已复用的 S04 或完全匹配旧阶段结果，不再被当成新 API 尝试占用 V04.1 内部 96 次 stop-loss。
- 章节规划器仅返回可靠导入索引范围，不让模型在一个 JSON 中反复手写约 200 条事实与媒体绑定；随后由程序将已核验事实按真实资产索引唯一归属。
- 模型在 S09B 阶段只选择图片，不再获准重写上一轮确定的章节结构和事实归属。
- V05 批量图片审核曾把多批嵌套字典直接合并，导致 25 张有真实图像证据的候选图被下游误认为全部无效。修复为按 P 编号合并所有批次的 candidate_scene_clues，且检查重复与缺失。
- 实际运行 25 张候选全部获得经过校验的逐帧事实引用；最终展示 16 段，具体展示数量由模型与发布规则决定，没有为了填配额而强制放入图片。
