# 04｜Web 实素材测试台

## 它能验证什么

- 手机素材解码和 Evidence 生成；
- Bundle V04 输入合同；
- Chapter/Aha 结果展示；
- 逐天、逐 Chapter/Aha、逐素材、逐表达的人工评价；
- 阶段时间、Token、估算费用和决策轨迹；
- HTTP 结果合同与失败状态是否被正确呈现。

## 它不能证明什么

- 真实耳机第一人称采集质量；
- 可靠时间/GPS 带来的聚类效果；
- 正式 App 的多次 Sync、无感上传和全天修订；
- 多用户并发、账号权限、数据保留和删除；
- Production SLA；
- V1.75 已接入。

## 当前输入合同

- 一次选择视为一个完整测试日，再次选择替换当前日；
- 当前不读取 GPS、拍摄时间或时区；
- 文件只保留 `sequence_index`；
- 照片生成 1 帧；视频按实际时长产生 1/3、2/4、4/8 或 6/12 个 Window/帧；
- Evidence 为 `768×1024`、3:4、aspect-fit letterbox、JPEG 0.84；
- 上限 240 项；该上限是测试台保护，不是产品日素材上限。

## 当前验证结果

- 快照完整性：通过；
- build：通过；
- lint：通过；
- tests：58 项中 57 通过、1 失败；
- 唯一失败：V1.63 Web 与 V1.75 新增策略字段之间的版本握手语义不完整；
- 结论：源码可接手，V1.75 接线尚不可验收。


保持快照不变并兼容现有脚本。它是迁移兼容层；后续完成正式 monorepo 配置后可以由新检查点替代，不得静默删除。
