# 06｜已知问题与优先级

## P0｜Web/API 不能证明实际执行 V1.75

现有 `/x02/v0.4.1/preview` 是历史默认入口，没有显式冻结 V1.75 identity 与 `recording_editor_policy`。应新增版本化研究入口，并让 health、result、audit 返回同源身份和合同哈希。

在此之前，任何 Web 结果都不能标为“V1.75 已验证”。

## P0｜真实内容质量尚未通过

- Pack 1 返回 4 Chapter / 0 Aha；
- Pack 2 返回 4 Chapter / 1 Aha；
- Pack 3 尚未完成；
- 两轮状态均为 `AWAITING_REAL_CONTENT_REVIEW`。

这证明链路可以返回，不证明 Chapter 聚类、素材精选、Aha 独立性和文案已经达到用户可用标准。

## P0｜Web 有 1 项版本握手测试失败

旧测试遍历后端所有 `runtimePolicies`，把任何字段变化都当成 Web 必须拒绝；Web 实际只依赖五项。V1.75 新增字段后形成歧义。

正确修复：

1. 精确 `algorithm_identity`；
2. 显式 `required_contracts`；
3. 可加法 `capabilities`。

错误修复：删除失败用例，或把 Web 临时写死为后端当前每个诊断字段。

## P1｜Aha 关系闭合过于脆弱

Pack 1 的模型提出了 Aha，但 Chapter/Aha 关系矩阵存在未解析项，最终全部保守拒绝。需要用真实结果评估：是请求结构导致模型漏填、合同过严，还是候选本身不独立。不能为了数量直接放松 gate。

## P1｜研究服务不适合多人或正式 App

- 同步请求通常 3–9 分钟；
- 一次性 Evidence 会占用浏览器与服务端内存；
- 无异步任务、重试恢复、队列和幂等；
- `ThreadingHTTPServer` 无正式容量结论；
- 本地 JSON 无数据库权限、备份和删除机制；
- 白名单账号尚未接入页面。

## P1｜输入分布偏差

手机素材通常主动、精选、第三人称且不连续；真实设备将是第一人称、自动、密集且更模糊。现有测试可以发现语义与编辑问题，但不能冻结真实日均 Chapter/Aha 数量或穿戴场景质量。

## P1｜时间和 GPS 缺失

当前只能使用导入序列和视觉语义，无法利用真实时间间隔、停留、移动轨迹或地点实体校正故事边界。未来应把时间/GPS 作为可选证据，不允许缺失时伪造。

## P2｜国际化未冻结

当前中文测试合同不能直接复制到英文。海外发布前需要按 locale 定义 Title/Story/Aha 的词数、布局、无障碍、评测集和发布 gate。
