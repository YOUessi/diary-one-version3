## 3. 最关键的问题：未入选的章被拆成三个Aha

S07没有提出任何原生Aha提案；现有候选构建仍保留18个有效备选。模型把Aha按“对各自Chapter的核心程度”排序，而不是充分比较最终独立卡片的价值和互补性。

实际过程：

1. 前12个备选属于最终已选Chapter，按同故事规则退出Aha。
2. 排序第13–15位是21（园区标识）、27（机构标识）、30（办公楼）。
3. 模型已将这三者都明确判为未入选的园区Chapter的SAME_STORY。
4. 园区Chapter因容量落选，这三个备选便一起占满Aha；Aha两两检查均为“未发现冲突证据”。

这不是“建筑不能做Aha”。真正的缺口是：**候选逐项排序，加上与Chapter的去重，不等于已经比较过最终三张Aha是否提供三种独立价值。** 同一个落选Chapter也不应不经整体比较就变成三张碎片卡。

这里不能直接加“同一候选章只能一个Aha”的硬规则；共同归属也不证明其中没有可独立成立的发现。下一步应先设计组合层面的编辑取舍，基于真实候选解释每张额外贡献，不添加建筑、人物或场景专用规则。
