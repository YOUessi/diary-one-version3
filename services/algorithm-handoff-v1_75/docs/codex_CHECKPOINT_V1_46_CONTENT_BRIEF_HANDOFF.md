## 内部交接合同

版本：`DIARY_ONE_X02_CONTENT_BRIEF_V01`。只用于 X02 当前 Storyline 路径；旧 V03/未标记的 Writer 输入继续原路径。外部路由、Writer Surface V02、Chapter Media V01、输出数量和 JSON 文案结构不变。

- `facts`：发送既有事实编号和原文，逐字不变；完整画面引用/支持等级仍留在原始上下文与账本，用于现有校验和回退。
- `content_brief.theme_hint`：Chapter 共同主题，仅组织提示。
- `content_brief.moment_hint`：Aha 现有内容职责，仅组织提示。
- `content_brief.materials[]`：当前范围内 observation_id、对应 fact_ids、原 contribution_hint。S10 是比较成员全集，S11 是实际精选集合。说明没有完整来源引用时不把不完整支持包装为完整贡献说明；不删事实或记忆。
- Writer 根据主题贴合、具体特点和新增意义自然取舍，不返回 focus_reviews、长理由或额外评分。这里没有新增兴趣评分算法，也不证明已具备个人偏好学习。
- 重试仅投影已有失败项，沿用当前唯一重写机会、次数预算、原文案校验和原回退逻辑。

可追溯性使用已有可扩展 `decision_trace.content_handoff`：记录政策版本、S10 输入/提示词指纹与素材/事实编号，以及准备好的首次 Writer 范围和输入/提示词指纹。不在诊断快照中重复事实正文或组织提示，不扩大原有自由文本记录范围；原始账本保留。它不记录隐藏推理，也不把“准备好输入”冒充外部调用成功；实际调用仍以 stage metrics 为准。外部 Schema 无破坏性变化。

新政策由当前流水线编排明确启用；通用 `_writer_context` 仍保持旧结构，历史实验工具不因调用它而自动切换提示词。重试显式继承新政策，旧未标记输入仍走旧提示词。

- [交接测试](../tests/test_codex_x02_content_brief.py)：10 项新增测试覆盖真实存档的字段传递、精选子集、历史兼容、现有重试及外部合同。它们不评价模型能否正确理解图像或写好文案。

与修改前的函数结构指纹对比：x02.py 仅 `_run_x02_impl`、`_writer_retry_context`、`_writer_prompt` 改变；媒体模块仅 `selection_prompt` 改变。原 `_writer_context`、事实校验、失败回退、分组、评分及资格判断函数均保持不变。网关、模型配置、调用预算、输出 Schema 和三项底线未修改。

交接例子：一章原有四项素材、最终精选三项时，Writer 只收到这三项的贡献说明与允许事实；第四项仍保留在原始账本。保留整体主题作为组织提示，不允许凭主题将第四项的内容补写进正文。这是数据范围说明，不是新构造的语义错误样本。

回归中发现并修正了两处兼容问题：诊断记录改用编号和指纹，避免重复保存事实正文；新政策只由当前流程启用，避免历史实验因复用上下文构造函数而悄悄切换提示词。未放宽既有测试或质量标准。
