## 5. 本轮能够得出的共性判断

1. **字数不是本轮主要问题。** 对照的短句可能有未支持的动作，候选的长句也可能清单化；适度余量和内容质量应独立处理，不用字数合格代替评价。
2. **不能只解释为上游没有可用信息。** 夜宵 Aha 的输入事实已有夜间街景、摊位与灯光，餐车 Aha 的输入已有售卖窗口、操作人员及窗前的人；候选仍选包装、颜色和招牌来写。至少这两例中，有信息但没有作出更好的表达取舍。
3. **组织提示仍可能影响事实关系。** 包 2 餐食事实未确认茶店，主题提示却写了 `tea shop`；候选随后使用“茶店”。两个鹿 Chapter 又把不同照片写成相反先后。可以记录为提示与事实边界的实际风险，但没有做去除提示的消融，不能宣称已证明唯一根因，更不增加“茶店”“最终”等禁词。
4. **该提示实现不接入，不否定共性取舍方向。** 本次没有证明某个物体数、属性词或场景模板有效，也没有建立新的语义门禁。继续叠加同义提示、把反例词汇加入规则，均不是本轮结论。

下一小步建议：停止提示词抽样，先将已有真实图、传入事实、组织提示和最终输出按同一条目对齐，区分“信息没有传到 Writer”“已有信息但取舍不好”“组织提示引入了关系”三类实际问题，再决定改哪个交接环节。这是离线定位与讨论，不是增加一条运行时流程。本轮已有两例第二类和关系风险的证据；不要为每一类预设必须改代码。

格式字段问题单独记录，后续验证接口层结构约束能力；不与兴趣取舍混成同一个修复，也不在本轮继续调用或假定严格结构化接口已经可用。
