## 3. 共性修复

当前 V04.1 路径采用 `DIARY_ONE_X02_FACT_RETENTION_V01`：

1. **200 字符是简洁目标。** S04 提示词要求模型尽量把每条事实控制在 200 字符以内，避免无意义冗长。
2. **1000 字符是数据安全边界。** 已有画面引用和结构合法的事实，可在 201–1000 字符范围内原样保存。1000 只用于限制异常负载，不用于判断生活内容是否值得保留；本次真实最大值为 491。
3. **保存不等于认同。** 这一步只避免程序因为篇幅删除模型事实；不证明事实语义正确，也不提高其支持等级。
4. **不偷偷改内容。** 程序不截断、不摘要、不拆句、不重写事实。否则可能改变事实含义或破坏原始证据可追溯性。
5. **原有事实校验继续有效。** 错误素材编号、引用未展示帧、空文本、无效支持等级或超过 1000 字符的异常负载仍按原合同拒绝；本次没有放宽这些边界。
6. **历史兼容路径不漂移。** 历史 V03 仍保持原 200 字符行为；新保留策略只在当前 V04.1 生效。

当 V04.1 保存一条超过简洁目标的事实时，逐素材审计账本增加：

`OVER_CONCISE_FACT_TEXT_RETAINED_WITHOUT_SEMANTIC_REWRITE`

S04 阶段状态同时声明策略版本 `DIARY_ONE_X02_FACT_RETENTION_V01`。对外结果结构没有增加字段，现有 Schema 形状不变。
