## 页面与流程

Welcome → Moments →（选 Something else 才进入 Custom → Custom review）→ Show less → Summary。初始不预选；两道题均可留空 Continue。

| 参考图状态 | 实现行为 |
| --- | --- |
| 欢迎页 | 原标题、说明、三条辅助说明、Get started / Skip for now；恢复说明与要点之间的留白 |
| 主题卡未选、已选、自定义入口 | 六张主题卡 + Something else + No preference，两列布局；保留任意多选组合 |
| 自然语言与搜索 | 原文保留；标准词及中英文别名搜索；手动搜索选项可移除，修改原文保留搜索选择 |
| 建议确认页 | 最多召回 3 个本地词库匹配候选；用户可移除、返回修改或跳过；只搜索标签也经过确认页 |
| 负向未选、已选、rather not、Nothing for now | 多选；Nothing for now 与其他项双向互斥；不要求解释不适原因 |
| 有具体兴趣、仅主题、明确无偏好的摘要 | 严格展示本次保留的选择，不补全未选的标签；未知表达在没有标准词时仍显示原文 |
| 全部留空的摘要 | Review your preferences；两处 Not set yet；Continue without preferences |

BACK 返回实际走过的上一步并携带修改；Go back and edit 回到当前问卷的 Moments，不依赖同名路由的模糊 navigate。Account 退出按实际问卷路由数量返回，避免可选分支导致多退页面。

文档规定 Skip setup for now 退出整个设置：首次使用保存 skipped 状态后结束，Account 重做则取消、不改已有记录。自然语言页 Skip this step 只清除本次补充，保留主题。图中的空摘要可通过两道题留空 Continue 到达。

为满足原文“可纠正”要求，确认页新增移除标签及返回修改入口；这两个交互控件是相对静态截图的必要补充。

## 数据含义与保存

- `preferenceSurveyResponse` 单独保存 `question_1_response=selected/no_preference/skipped`，以及第二题 selected/nothing_for_now/skipped；明确回答不与未回答混用。
- 每条主题偏好只写一个 `theme_id`，不展开成家人、朋友、徒步等具体兴趣。Something else 和 No preference 不产生主题记录。
- 标准兴趣保存稳定 `tag_id`；模型制作归 `activity.diy` 等已有词。未知名字/兴趣保留私有原文，不新造公共词条，不猜 Dou Dou 是宠物。
- 负向记录包含 `preference_reason_id` 和内容特征范围，只降低展示权重；不变成负向素材 Tag、删除、隐私屏蔽或设备采集设置。
- 使用本地受控词及别名匹配，**不是已接入通用 AI 语义理解**。不明确的表达留原文，由用户搜索或修改确认；不伪装成模型理解成功。
- 用户在其他入口添加的偏好保留；确认重做只替换问卷来源记录（含旧 `survey-` ID）。主动选择无偏好可撤销本题原有正向信号。
- 手动编辑卡片后清除过期的结构化 scope，保留修改后的原文，避免旧 ID 继续代表新文本。
- 偏好、回答状态及完成标志在进入主界面之前等待本地持久化；错误提示可重试，恢复旧记录；切换账号后不回写旧问卷。
- 本轮不向素材、Chapter、Topics 写入兴趣事实。云处理同意、人脸声纹、通知、隐私规则仍使用各自流程。
