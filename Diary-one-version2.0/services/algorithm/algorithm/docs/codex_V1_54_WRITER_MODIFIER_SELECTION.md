## 1. 共性原则

**修饰信息是否值得写，取决于它对这条记忆的作用，而不是它属于哪种词。**

删除后不影响核心理解、主体辨识、场景特点或必要画面感的信息，优先不写。颜色、材质、包装、装备、细分类别、镜头方位和背景物不是禁写类别，也不是必须保留的识别清单。

不把“故事一般不描述颜色”扩大为全面禁止色彩或外观；静态场景的美感也可以是核心，不强迫所有卡片围绕动作。不把简洁等同于删去所有具体性，更不在删掉细节后用空泛感想填满篇幅。

## 2. 精简后的通用写作指导草案

> 围绕这条记忆值得留下的主体、动作、互动或场景特点来写。外观、材质、包装、装备和镜头方位等，如果只是交代物体长什么样或位于画面哪里，可以省略；能帮助理解内容、区分主体、体现场景特点或支撑画面氛围的细节则按需保留。不必覆盖所有识别结果，也不凑固定数量的物体或细节。省略修饰不能改变原意、丢掉必要关系或提高原有识别的确定程度；不要用空泛的氛围总结填补删掉的细节。

这是将来精简/替换既有取舍段落的编辑草案，不是在旧提示或 V1.53 候选提示后继续累加的一串规则。它没有被发送给模型，也没有证明优于原提示。既有事实来源、Chapter/Aha 职责与字数方向不因此改变。
