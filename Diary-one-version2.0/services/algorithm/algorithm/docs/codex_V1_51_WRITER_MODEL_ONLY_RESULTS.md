## 4. 这次真实返回证明了什么

1. Flash 在这组输入上的 Aha 正文更短，最终交付由 0/3 改为 2/3；这是可保留的局部收益。一次对照不能推出稳定成功率。
2. 第一次返回六条都缺必需字段。实际 HTTP 请求包含原 Schema 的 required 字段说明，原提示也要求返回引用；不是实验工具漏发要求，也不是解析器删除了引用。原始响应内容与解析后输出逐项相同。
3. 当前接口使用 JSON Object 模式，并把 Schema 作为提示文字附加；本次没有启用接口层严格字段约束。能返回合法 JSON，并不意味着已满足项目输出合同。是否可在该模型使用更严格接口需要单独核实，未在这次模型对照中顺带更改。
4. 当前逐项校验在遇到缺引用时即退出。石碑 Aha 的审计虽记录了实际 24 字，但没有附上“20 字上限/超长”这一项明确失败；唯一重试反馈重点是缺引用。重试补齐引用且保留全部正文，说明一次返回所有**已经存在且可独立确定**的格式问题有实际检查价值；尚不能证明改善反馈一定能让模型完成改写。
5. 不把格式问题归因于视觉模型认错物体，也不为纠正实际措辞追加场景/关键词规则。文案重点、自然度和原分组质量仍需分开评价。
