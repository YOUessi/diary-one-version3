## 2. 已确认的进展

### 2.1 Chapter 分组显著清楚

三个 Chapter 分别围绕街市摊贩、庙宇庭院、犬只同行展开。古镇作为共同大背景没有把它们重新混成一个泛化故事；街市、建筑文化体验和同行活动承担不同叙事职责。最终每章保留三件素材，画面内部基本一致。

这证明 V1.72 “只从事实组织故事、不给派生标签充当证据”的方向有价值，但只是一包真实结果，不能证明所有用户场景已经稳定。

### 2.2 逐对关系闭环真实生效

本轮 3 个 Chapter × 3 个 Aha 的 9 条关系，以及 3 个 Aha 两两之间的 3 条关系均由同一次 S07 返回并成功绑定。没有缺失关系、程序补关系、分数代替关系或追加模型调用，执行状态为 `COMPLETE_CLOSED_RELATION_RECOMMENDATION_EXECUTED`。

这解决了 V1.71 “选出卡片却没有逐对说明是否重复”的结构缺口。关系仍是模型的编辑判断，不等于视觉真值。

### 2.3 本轮三个 OCR 结果经画面复核并非幻觉

三个入选 Aha 所依据画面中，地点牌匾、摊位招牌和石碑文字均能看到对应文字。因而本轮没有证据证明 OCR 错认；不应为了设想中的 OCR 错误增加关键词规则。保留“不清晰时降级、不把不确定写成确定”的通用证据纪律即可。

## 3. 阻止 V1.72 验收的真实缺陷

### 3.1 Writer 模型违反 24 字合同，但本地硬门槛先正确拦截

模型一次返回的三条 Aha 正文分别为 32、31、32 个可见字符，均超过 24 字。结构化 schema 中虽然已有 `maxLength: 24`，当前兼容接口实际只保证 JSON object，并没有供应商侧受约束解码；因此模型仍可能违反长度字段。

本地验证器正确给三条都标记 `AHA_MOMENT_LINE_OVER_24`。这说明“本地出口作为最终门槛”是必要的，也说明不能把 schema 写入请求误称为供应商强制执行。

### 3.2 确定性兜底绕过了同一硬门槛，这是严重出口错误

在模型文案被拒绝后，程序构造兜底上下文时漏掉了 V1.72 Writer 策略字段，导致后续验证退回旧的软长度规则。三条长达 61、111、37 字的原始事实因此以 `DETERMINISTIC_GROUNDED_FALLBACK` 重新进入公开结果，交付状态还被标成 `READY_WITH_GROUNDED_COPY_FALLBACK`。

这不是模型随机质量问题，而是确定性的程序逃逸路径。只要最终出口仍能绕过 24 字门槛，V1.72 就不可验收。

### 3.3 “一条 fact”没有等于“一个 Moment”

S04 前半部分较常把不同画面拆成不同事实，但后半部分仍出现一条事实横跨多帧、组合摊位全景、人物操作、招牌和商品的情况。S07 虽然只选了一条 fact，实际仍把多个可分离细节交给 Writer；Aha 画面也随该事实带入三至四帧。

因此 V1.72 只实现了字段数量上的原子性，没有实现用户看到的单一瞬间。不能用程序按标点切事实，因为那会制造新的语义判断；应让同一次 S07 在原事实内明确选一个焦点帧和一个焦点表达，再做引用校验。

### 3.4 Aha 的“独立价值”仍不够稳定

摊位小发现具备独立回看价值；石碑可作为文化发现候选；地点入口牌匾更像 Chapter 的地点上下文，未必本身就是值得单独回看的小惊喜。本轮关系矩阵只证明它与其他卡片不重复，没有证明它值得成为 Aha。

下一版应在同一 S07 编辑判断中明确：仅承担地点标签、背景说明或分类信息的素材不足以独立成 Aha；Aha 应当能作为一个小发现、互动或转折被单独回看。该要求是通用编辑原则，不做任何场景词拦截。

## 5. 结论与下一小步

V1.72 的逐对关系架构和 Chapter 分组方向保留；V1.72 本身不接受。下一候选必须作为 V1.72.1 单独封存，不能覆盖本记录：

1. Aha 选择同时绑定一条事实、该事实中的一个焦点帧和一个简短焦点；最终 Aha 只展示这一帧。
2. Writer 只围绕一个主体和一个动作或发现表达，非必要背景不进入正文；原事实仍随请求提供用于事实校验。
3. 24 字由本地唯一出口强制；模型超限时只阻断对应 Aha，不能调用 API 重写，也不能用长事实兜底发布。
4. Writer 采用同一链路已有的 Plus 文本模型做一次生成，提高结构遵从概率；本地门槛仍是最终权威，不宣称模型一定服从 schema。
5. 只补充通用 Aha 独立价值要求，不增加地点、动物、建筑、文字等场景特例。
