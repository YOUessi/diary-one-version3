- 文案：具体哪句话生硬、重点错了或没有依据；允许适当氛围，不要求列举所有物体。
- 每条记录：包 ID、运行 ID、版本、Chapter/Aha ID、素材 ID 或句子、问题类别、用户意见、旧/新更好或相当/无法判断。编号由运行结果生成，不预编评价答案。
