## 1. 已发生：四个模型分组因辅助说明长度不合规而整体退出

日志中的四个 `MODEL_STORYLINE_PROPOSAL` 都被记录为 `STORYLINE_CONTRACT_INVALID`，具体原因均为 `storyline.thesis length is invalid`。

其中模型提名的一个组包含 `09.jpg / 08.jpg / 06.jpg`，另一个包含四张骆驼素材。这至少说明模型给出了与最终混合组不同的成员划分；不能把结果都归因于模型没有提出分组。

当前代码仍在 `x02.py:4220` 要求内部主题说明 `thesis` 长度在 2–160；不合规会拒绝整个候选。发给模型的 Structure Schema 对该字段仅声明字符串，没有同样的长度约束。

证据限制：日志没有保留原始 thesis 全文，无法确认当时究竟是过长、过短还是空串，也无法恢复准确字数。不能将该原因改写成“已证实超过 160 字”。模型分组被保留也不代表它们必然通过其他检查或得到用户认可。

建议：把素材成员、事实引用等核心结构与辅助说明字段分开处理。辅助字段不合规不能自动等同于整个内容分组无效；先完成这一处局部设计与修正，不增加场景例外。

该候选来源是 `DETERMINISTIC_FOCUS_EPISODE_PARTITION`，不是模型故事方案。

对应机制：`_storyline_focus_candidates` 用固定类别和词表产生“沿途景色”等主题；自动分组按主题、导入位置合并；UNKNOWN/OTHER 的 Episode 被放进同一个 `FOCUS_ONLY` 桶。这些相同标签不足以证明同一次活动或一条独立故事。

建议：保留 Canonical Tag 的检索与数据价值，但不让标签代替内容关系判断。不能用增加“相机、鹿、餐车”的分类分支来修这一组。

## 3. 已发生：“同一故事”检查没有拦住混合组

该组有 6 个候选成员、导入序号跨度 11、6 项穿插内容、穿插比例 0.5、3 个片段，检查结果仍为 PASS。

当前条件是“跨度 ≤12，或者穿插比例 ≤0.34”。这组因跨度条件通过；成员数、片段数、Beat 数量也通过。Episode 都未知，没有形成已知 Episode 之间的拆分信号。

这不是说应把 12 改成另一个数字、把 OR 改成 AND，或强制按白天/夜晚切分。它说明：当前关卡主要检查结构数量，不能据此宣称已验证内容属于一个故事。导入位置也不是可信时间。

## 4. 已发生：混合组仍获得较高内部分数；分数有效性未验证

该混合组的 `storyline_value` 为 0.861667。

当前公式为：40% 素材画质 + 30% 事实支持等级 + 20% 成员数量深度 + 10% Beat 类别多样性。它没有直接评价“这些内容为什么应该同组”。后续的 0.52 / 0.56 / 0.60 / 0.72 门槛也不是用户满意度概率。

已确认的是公式、门槛与这次真实分数；尚未证明的是各权重如何影响不同用户的满意度，不能凭这一个包给出新的“正确权重”。

建议：暂不调分数补救错误分组。先使候选具有清楚的内容关系，再用真实成员级评价讨论排序。自动按数量均分为两组/三组的策略也仍属待验证研究逻辑，本次不新增规则。
