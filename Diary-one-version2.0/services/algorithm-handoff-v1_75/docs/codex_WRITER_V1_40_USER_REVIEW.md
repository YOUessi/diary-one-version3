## 为什么格式过了，仍然不好用

目前程序检查的是：条目齐全、编号有效、引用来自该条目、长度和句数符合合同。它不会将“像不像自然回忆”“是否真的有独立价值”伪装成已经证明的事实。

现有模型请求其实已经要求自然改写、克制氛围、不要罗列全部事实、不要使用分号清单，并把 Chapter 的 48 字设为软目标。但本次输出没有充分遵循这些写作目标。这是实际表现，不是“没提前提要求”；也不能据此断言模型永远做不到。

另一个已查到的输入问题：Writer 收到了详细的分组解释和素材结构，但没有显式的“这些素材无可靠拍摄时间”字段。分组解释中又有过程性推断。它是否导致本次“随后”，尚未做对照验证；目前只是有证据支撑的原因线索。

## 本轮边界与下一次讨论

这是已有真实素材的 Writer 单阶段验证：复用素材包 2 的历史分组和精选，不是重新导入、重新识别、重新聚类的全流程测试。三个 Chapter 保留原来的 4/4/5 个素材，没有执行新的去重。历史只有两个素材的相机章节不纳入本轮展示样例，原记录未删除。三个 Aha 是上游历史候选，本轮新产出的是其文案，不是新证明了它们应当入选。

本轮已人工查看 13、09、20、19 四张原照片并核对所引用的六张封面/Aha 原图指纹；没有宣称逐图完成整个素材包的视觉准确率审计。所有图片链接指向本机授权素材，不复制进仓库，也不随文档同步上传原图。

建议先挑 C1 和 A3，各讨论出一句你认可的表达，用来明确通用标准：保留什么、舍弃什么、氛围到什么程度。它们只能是评审样例，不会直接固化为骆驼或餐车的专用规则。没有你的措辞偏好反馈前，不接入测试页，不自行开启另一轮大范围调整。
