## 3. 共性方向：约束表达重点，而非数物体

以下是下一次对照的设计方向，不是已通过真实质量验收的新算法：

1. **先明确这张卡片想留下的核心。** Aha 围绕自身瞬间；Chapter 围绕已有分组的共同体验，不把每个素材都分配一句介绍。没有共同体验的分组问题不能靠 Writer 编造故事补齐。
2. **细节服务核心，不平等罗列。** 保留能让核心更具体、可辨认或有画面氛围的内容；普通属性和背景不因“已识别出来”就必须写入。比如林径犬的动作与路面环境可能比毛色、背带更值得占篇幅，但这不是禁止写毛色、背带的场景规则。
3. **不设物体配额，也不凑细节数。** 一组物体可以共同支撑一个重点，一个物体也可能带出过多无关属性。没有必要固定写两三个、三四个。
4. **取舍只影响展示文字。** 完整事实及其来源仍保留，不为压缩文案删除检索信息；不假设系统已知道某个用户的真实兴趣偏好。

现有 `codex_content_brief.writer_prompt` 已要求“选择最值得说的核心”“不要逐个列举物体”。所以不能把重复这两句话称为新方案已经落地。值得验证的差异是：是否更清楚地区分核心与辅助信息的职责，并允许不承担表达作用的细节完全不写；不能继续堆叠同义要求、场景词表或额外评分/理由字段。
