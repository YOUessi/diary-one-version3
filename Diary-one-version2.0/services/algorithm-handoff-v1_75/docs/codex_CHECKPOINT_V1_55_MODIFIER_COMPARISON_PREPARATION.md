## 3. 看什么结果

按每条真实输入并排保留两版原文，人工分别记录：

- 取舍：少写的是否确实是附带属性，而不是丢掉核心。例：林径犬的外观可省，但不能只留下“小狗”标签。
- 具体性与自然度：能否读出场景，又不成为设备识别报告。例：夜宵输入已有街景和灯光，不需要依赖包装与材质撑满一句。
- 必要关系：省略是否改变原意或让人混淆。例：餐车内操作人员与窗前的人，位置关系仍可能重要。
- 长度与格式：分开记录字符数、字段和引用情况；不把 24 字设为新硬门槛，不把合法引用等同于语义正确。
