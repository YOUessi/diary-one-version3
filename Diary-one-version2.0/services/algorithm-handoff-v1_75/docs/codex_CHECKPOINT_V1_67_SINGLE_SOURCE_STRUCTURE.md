## 最小变更

1. Chapter 的 `beat_map` 是模型唯一提交的逐素材成员/事实清单。
   顶层 `observation_ids` 和 `fact_ids` 不再要求模型重复填写，由程序从该清单派生。
   实际逐素材未知编号、错绑、无效结构仍由既有验证处理，不猜补成员、事实或说明。
2. 原生 Aha 不再自行生成另一套 key，统一使用输入已有的 `observation_id`。
   每个 Chapter 自带 `aha_relations`；关系行同样使用 `observation_id`，
   程序按其所属 Chapter 补内部引用，不要求模型在关系表里再复制 Chapter 名称。
3. 一层小型格式转换将新输出变为既有内部候选格式，保持后续选择/精选/文案接口不变。
   原始回复与转换记录分别保留，不用派生结果覆盖原始模型输出。
4. 关系仍需模型判断、事实引用仍需验证。新格式降低重复抄写负担，不保证模型永不漏项；
   缺失仍记未决，不追加所有未决一律封杀的规则。

模型只负责内容组织；程序负责可确定的汇总和引用。关系说明不是新事实。
同一主题不自动证明连续经历，旧时间/GPS缺失限制保持。
