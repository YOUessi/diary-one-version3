# Diary One Algorithm V1.74｜完整事实 Aha 编辑与 Writer 安全出口检查点

日期：2026-09-15。状态：**本地实现与完整回归通过；等待冻结候选和素材包 1 全新真实链验证。**

## 1. 本步修复的真实问题

V1.73 素材包 1 的真实运行证明了两个问题：

- S07 在兼顾 Chapter 与 Aha 时，把 35 条完整事实压成 5 个 Aha 候选，并把一条包含人物操作、设备与摊位陈列的事实压成了店名识别；S09 无法从已经丢失的信息中恢复体验价值。
- Chapter Writer 已生成可读文案，但复制长 UUID 时出现一处字符错误，整卡随后使用原始英文事实兜底，形成不可用成品。

V1.74 只修复这两个真实问题，不重新设计 Chapter 聚类，不增加场景关键词或虚构语义错误门槛。

## 2. 新职责边界

```text
S04 视觉事实 + 每条事实的代表帧
  → S07 只生成和选择 Chapter
  → S09 一次纯文字调用读取全部可用事实并选择 0–3 个 Aha
  → S10 Chapter 选 3–5 个素材；Aha 使用事实代表帧
  → S11 一次 Writer，模型只见请求内短编号
  → S12 发布完整卡；Writer 失败的 Chapter 只进入内部素材账本
```

正常模型调用数不增加。S09 仍是一次 Plus 文字调用，Writer 仍是一次 Plus 调用；没有重写抽卡，没有自动补位。

## 3. S04 代表帧

研究入口为每条事实增加 `representative_frame_id`，且它必须属于该事实的 `evidence_frame_ids`。S04 是实际看过图片的阶段，因此由它选择哪一帧最能代表该事实。

代表帧缺失或越界时：事实仍保留给 Chapter 与事实账本，只有该事实不能进入本轮 Aha；不拿第一帧自动代替，不删除整条 observation，不重试模型。

## 4. S07 Chapter-only

S07 仍读取全部事实，完成 Chapter 候选、成员、beat map、内部主线和推荐集合；`aha_proposals` 与旧 Chapter 内 Aha 关系必须为空。Aha 的发现、筛选和跨卡关系不再挤在同一回复里。

这不修改既有 Chapter 产品边界：每个 Chapter 至少 3 件、最终 3–5 个精选素材，常规最多 4 个；聚类仍由素材事实与整体 storyline 决定，不按标签机械分组。

## 5. S09 完整事实编辑

一次纯文字 Plus 调用读取当天所有满足以下条件的事实：所属 observation 为 `KEEP`、支持度为 `STRONG/MODERATE`、代表帧合法。输入不包含原图、motif、事件类别、画质分、对象稀有度或未经提供的用户兴趣。

模型在同一次回复中：

- 从完整事实池列出最多 8 个便于审计的 finalists；
- 只按候选自身回看价值标记 `WORTH_REVISITING / WEAK / UNRESOLVED`；
- 从 `WORTH_REVISITING` 中选择 0–3 个原子 Aha；
- 为全部已选 Chapter/Aha 与 Aha/Aha 对返回唯一关系矩阵。

关系矩阵是跨卡重复的唯一裁决来源。`SAME_STORY` 或 `UNRESOLVED` 只关闭受影响 Aha；其他成立项保留，不从落选项自动补位。程序只校验引用、原子事实、数量和关系完整性，不替模型判断精彩程度。

现有三套真实素材的事实规模已在上下文可承受范围内；186 素材高强度日尚未验证。V1.74 记录 S09 的事实数和序列化字节数，但不在没有容量证据时发明截断规则。

## 6. S10 与 Writer

- Aha 的唯一事实由程序绑定到 S04 的代表帧，不新增视觉调用。
- Writer 请求把真实候选、事实和 observation 编号私下映射为 `C01/A01/F001/O001`；回复恢复真实编号后，继续通过原有引用和格式门槛。
- Aha 正文仍以 20 个可见字符为目标、24 个为硬上限；Chapter 仍默认一句、最多两句。
- OCR 不确定、动作最低强度和不编造要求继续生效。
- Writer 只调用一次；未知、越界或跨卡短编号使对应卡失败，不猜测、不二次调用。

## 7. 已确认的 Writer 失败体验

Chapter Writer 失败时：

- 不公开坏文案；
- 不把原始事实或通用套话冒充成品；
- 内部 `media_only_chapters` 账本保留 Chapter 身份、storyline、3–5 个精选素材、封面和事实引用，等待未来产品层决定如何呈现或修复。

Aha Writer 失败仍只保留内部阻断记录。当前 Web 公开结构要求 title/story，因此本步没有修改 Web schema 或切换 Web 默认。
