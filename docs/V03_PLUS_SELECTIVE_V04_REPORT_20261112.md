# Diary One｜V03 基线 + 精选 V04 规则：真实实验与交付

**日期：2026-11-12。状态：实现完毕、独立测试中；默认关闭，未部署线上。**

## 核心实现

- 冻结原始 V03 源码，保留 1210 字符的原始 Prompt、8图硬上限、3–6图建议、原 Qwen3.8-Flash 单次全图请求接口、原手机/BFF V01格式。
- 新增研究候选 V03+，精选的四条 V04 规则仅多约302字符：封面须代表本章、支持图承担不同信息角色、重要艺术品/动物/建筑/独特活动须有具体可见证据、title/story/key_moments为简体中文。不给模型增加10–20图配额，不重写V03分章标准。
- 对照变体：较长六条规则（约557字符增量）与再加一条强制时间说明（额外117字符）。两者实测不稳定，不推荐使用。
- 新研究开关 DIARY_ONE_X02_EDITOR=direct_vlm_v03plus；未设置时原V03主路径完全不变。BFF独立实验发布开关 DIARY_ONE_ALLOW_V03PLUS_PUBLISH=1 默认为关闭。
- 程序对模型原始输出执行严格图片编号、同源Clip跨章归属、非法Key Moment、重复、图库限8、机械满额分桶及时间覆盖检查。失败允许最多一次相同请求重试；不可用时拒绝，不自动裁剪、挪图、重排Story。
- 旧V03转换器会把已选图之间所有未选图自动扩张为本章证据；V03+在发布前改为只记录明示选择的Gallery+Key Moment Frame ID，避免错误声称其他场景属于该章。
- 质量日志明确 gallery_semantic_verified=false：结构合法不代表作品名、封面、经历归属正确。另有CNY1.20默认预算预检。

## 实际图片质量发现

- 博物馆精选版两次的4章划分比原V03的7章更接近完整参观经历，主要选图时序连续。但一次标题写“雕塑花园”，图片实际上是室内雕塑展厅；仍存在事实命名不准确。
- 国家公园精选版第二次6章22图无时间交叉，但第一章包含两张来自同一个10秒Clip、画面高度相似的车辆/道路图；重复选图并未完全消除。某些具体峰名是否正确仍未经独立可靠证据确认。
- 悉尼offset30精选版将JPEG#133（Clip91）的教堂图选入后面的第7章，而第6章图已经到Clip101，属于跨章时间污染；两次均未消除这种问题。
- 悉尼offset10第一次精选版9章24图，大致按歌剧院、市集、海港桥、滨水区、海事博物馆、唐人街、商业与教堂、公园、植物园推进，实际图片归属较清楚。但多章仅2图，可能丢失重要视角；不能只因为比历史V03的63图更少就认为效果更好。
- 悉尼offset10精选版第二次出现相同JPEG被不同章选用，依然失败。单次结果良好不能代表模型足够稳定。
