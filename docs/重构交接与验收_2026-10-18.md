## 4. 同事接手顺序

1. **先修复云端模型权限并重跑生成验收。** 本轮 BFF/Worker/X02 已部署，公网 health 返回 `v2-20261018T132121Z`。隔离测试已验证账号删除及 DB/MinIO 清理；真实 Worker 到 X02 的调用被千问 HTTP 403 拒绝。已有服务镜像、数据库、账号文件和源码/配置备份，MinIO 原卷保留。详情见部署记录；不要调用真实用户 DELETE 接口做冒烟。
2. 服务端 `.env` 新增 `GOOGLE_CLIENT_IDS`，填逗号分隔的实际 Google Web/iOS Client ID；App 的 `EXPO_PUBLIC_GOOGLE_*` 不会自动配置服务器。Worker 的 `WORKER_RECOVERY_GRACE_SECONDS` 默认 120。compose 已透传。
3. 当前 JSON 会话/配额存储按**单个 BFF 进程**使用；不要直接扩为多个 Uvicorn worker/实例。扩容前迁移为共享事务存储。Worker 长模型调用期间持有 DB 行锁，应评估数据库连接数、超时和费用；不是 exactly-once 外部调用保证。
4. 在隔离环境实际演练：Redis 丢失通知、Worker 被杀后恢复、重复入队、同邮箱并发提交、账号删除与上传互斥、对象存储失败后的删除重试。删除响应丢失且 token 已撤销时，重新登录同邮箱后再次删除；云端已确认而本地失败时重启继续清理。
5. 填公司 Apple/EAS/Google 配置，执行 preview 的 store 分发构建；验证 Vision pod、iOS 16.4/17+ 分支、签名与真实 Apple/Google/OTP 登录。Windows 上的 Hermes export 不能替代这一步。
6. 真机用自己的照片/视频走完整链路，再按上节 17 页矩阵拍摄页面和状态截图，之后再发 TestFlight 内测。

## 5. 仍需明确或完成的产品/运营工作

- **真实算法质量**：本轮修复输出合同，没有重训、替换选章/Writer 算法，也没有跑新的真实千问质量评审。需用团队同意的真实素材核查选章、事实、封面、Small Memory、长视频成本。
- **增量语义**：同日批次是保留式合并，不是把全天原素材重新跑一遍累计聚类；跨批重复语义/主题合并仍需专门设计。没有伪称完成全天重计算。
- **搜索**：当前按 PRD SEA01–03 明确使用本地 Basic Search；语义检索/Agent 属另立需求，不是当前必须补齐项。Topics 仍是本地启发式聚类，长期信号可靠性待验收。
- **偏好云端闭环**：现有 `EXPO_PUBLIC_UPLOAD_MEMORY_PREFERENCES` 默认关闭，本轮没有静默开启；开启与隐私文案/同意范围必须一致。算法端支持 soft boost/avoid 不等于 App 默认已上传偏好。
- **媒体原生细节**：精确 50% 可见面积暂停、音频焦点/系统打断、低内存、取消中仍在渲染的临时分享文件回收需要真机验证。当前应用私有目录清理不代表系统照片备份或用户已经分享出去的文件被删除。
- **云端留存/孤立对象**：现有上传在 DB 提交前可能写入对象；故障产生的无作业孤立前缀需运维清扫及留存规则。不能仅凭删除路由声称所有历史孤立对象、备份、服务商日志已清除。上线前要明确可验证的生命周期和保留说明；App 已去掉未经验证的“自动原片短暂留存”承诺。
- **补记恢复**：删除前内容保存在 story_revisions，用于恢复；尚无用户恢复界面或跨设备补记同步。
- **其余历史缺口**：通知设置尚非真实推送投递验收；界面语言/记忆生成语言不能因设置已保存就宣称全语言闭环；Help/反馈、订阅计费、正式隐私政策/Terms URL 仍按真实产品状态验收。
- **硬件**：本轮不接 BLE、不宣称自动拍摄/同步完成，不编造设备遥测。不要因为 Device 留占位就误判软件导入链路无效。
