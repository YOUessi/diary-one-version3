## 人工查看真实封面的主要观察（只作为逐图初审）

- **悉尼**：V02 第1章封面有文字叠层；第5章“皮尔蒙特桥与中国城”的封面是普通城市广场，而本轮 V03 对应中国城章节展示了更有辨识度的商业街；V02 第7章绿地封面和自然经历基本一致；第8章麦考利夫人座椅标题与海滨步道封面不完全匹配。
- **国家公园**：V02 的六段活动（山脊、森林、路口、下降、营地等）在视觉上有一定差异，但出现多对相似图库照片；叙事提到特定步道/瀑布时还需确认有足够图片证据。
- **东京**：V02 部分封面可对应公园、寺庙、夜市等视觉主题；“歌舞伎町与新宿街头夜行”封面显示明亮的白天商店街，出现时段措辞与可见画面不一致；“尾山神社”“六本木新城夜间庭园”等具体地名没有通过独立可见牌匾核验。
- **博物馆**：V02 首次因 Key Moments 超出10条而被拒绝；第二次同输入独立重跑成功，但这恰好说明单次合同通过率仍不稳定。Direct V03 把同一次参观拆成9章，存在过度切分风险。

## 工程判断

**保留单次 Direct VLM 为默认；Planner + Gallery V02 继续独立研究开关。** 目前 V02 的优势是由程序确保所有 source clips 有连续且唯一的归属、每个 Gallery 调用只能看到本章 JPEG，并通过完整结果绑定。代价是更多调用、延迟和可能的图库冗余；其语义事实与封面质量未充分验证。

下一轮优先：统一每章图库上限（当前 V03=8、V02=20），减少/约束 Key Moments 越界失败，独立跨域审图校准作品和地名，基于真正用户十秒视频的 Bundle V05 与 Live/Motion 端到端测试。独立实验不应直接替换线上服务。
