# 保留已核验Chapter主旨与封面

用户要求调整审核边界，保留悉尼案例中已经识别的歌剧院、分章阶段的城市漫步主题和歌剧院封面。原始R5_21结果保持原样。

## Approaches

采用：把完整、已核验的核心事实及原主题传递给文案阶段；最终审核按实际引用组织图片批次，避免全局24张筛选把已引用图片遗漏。保留独立图像否决和引用合同。用户已指定保留的结果和调整目标，具体接口为本次实现选择。
未采用：强制写死悉尼歌剧院或固定标题，会变成案例特判；仅提高24张常数仍会随素材量再次丢证据；关闭最终审核会放过动作/空间关系幻觉。

## 行为

1. 经图片审核的核心选图事实和原主题进入重点选择、写作及文字审核；摘录不能成为遗漏主体的唯一信息源。主题是编辑方向，仍要独立图像验证，不能当新增事实。
2. 最终证据目录可包含全部合格引用，但每个真实请求仍仅发送该标题/句子引用的图片，单个主张上限24张；超过上限为未核验，不是语义错误。缺失/错归属图片仍不放行。
3. 未取得图像判定的标题不进行以其他内容替代的标题修复。原封面仍支持最终标题时优先保留；只有最终通过的标题确实由另一张已选图支持，才重选。
4. 不改变抽帧、分章粒度/上限、事实复核8批上限、选图18张上限或部署。

## 验收

以真实悉尼既有输出复现缺失F023绑定和主旨上下文丢失；自动回归覆盖超过24张目录但单次小批审核、外来/缺失图片拒绝、核心事实不被字幕片段替代、未审核不等于否定、原封面保留及真实否定仍阻拦。必要的真实API验证固定既有分章/选图，只验证更改后的文案后半段，明确不称完整重跑。
